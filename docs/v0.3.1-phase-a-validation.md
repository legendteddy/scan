and ScanBench used bundled fixtures. No tests were weakened to pass these gates.

The four local skips are file/directory-symlink tests because this Windows host
returns WinError 1314 (missing symlink creation privilege): external symlink
inventory, internal symlink-loop inventory, the existing native file-symlink
regression, and the new Git-ref/config file-symlink regression. Each reports its
explicit reason. Native Windows junction tests did run, covering external ref and
config directories, inventory scope and a parent replacement before opening the
file. ScanBench explicitly reports its native junction substitution. These skips
do not represent tested file-symlink behavior on this host.

Before changes, the local Core suite failed in ScanBench's setup when it attempted
to create the unprivileged symlink fixture. The junction fallback exercises the
actual native reparse escape with the original fixture assertions; it does not
mock the boundary or silently omit the fixture. Fixture creation uses the Windows
API directly, with no shell interpretation of path names.
